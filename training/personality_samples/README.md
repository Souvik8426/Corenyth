# Corenyth personality samples

40 synthetic English examples: 10 per personality. These are preview seeds, not a complete fine-tuning dataset. Responses are concise; no model-specific chat tokens are embedded. Apply the selected Gemma checkpoint’s tokenizer chat template when preparing training.

Dataset rules: never use the em dash character (Unicode U+2014). Professional responses acknowledge emotional context with brief empathy while staying concise.

Each row contains metadata and a system/user/assistant messages list. Train on assistant responses only. Keep all rows sharing a scenario_id in the same split when expanding this set. No train/validation/test split is provided for this small preview.

The reminder example asks for the missing day and does not claim a reminder was saved. This conversational format differs from the app’s existing plan JSON contract and needs an explicit integration decision before production training.
